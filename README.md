# HENDY Cybertech + Admini Bot V3 Settings + Local Vietsub

This build integrates the legacy HENDY Cybertech Telegram menu with the V3 `⚙️ Cài đặt bot` menu, Admini Mini App, automatic spoken-language detection, offline subtitle translation and video burn-in.

## Security first

The original pasted source contained a literal Telegram bot token. This integrated source removes it and reads the token only from `BOT_TOKEN`. **Revoke the exposed token using @BotFather and generate a new one before deployment.** Never put real tokens in GitHub or in source files.

## Preserved legacy menus

The existing HENDY Cybertech menu actions and callback logic were carried over: code center, social services, deposits, customer center, Vietsub pipeline, Compose Web/TMA, support, and admin area. Existing core backend requests remain configured through `CORE_BACKEND_URL`. Some old mock operations (wallet balance, check account, orders, etc.) are still in-memory placeholders and are not durable production records.

## New V3 Settings and subtitles

- Main menu includes `⚙️ CÀI ĐẶT BOT · VIETSUB`; `/settings` also opens it.
- Settings are saved per Telegram user ID to `SETTINGS_FILE`.
- Modes: ask every time, original-language SRT, Vietnamese SRT, or MP4 with hard-burned Vietnamese subtitles.
- Sending a Telegram video, video note, or video document starts the selected workflow.
- Whisper.cpp runs locally and detects the spoken language automatically.
- Argos Translate translates locally; no OpenAI API key or hosted paid AI endpoint is used. Additional language-pair models may be fetched on first use.
- FFmpeg extracts audio and can burn the Vietnamese SRT into a new MP4.
- The Mini App has four Admini cards with CSS color effects and server-side validation of Telegram `initData`.

Telegram Bot API cloud downloads typically have a 20 MB source limit; `MAX_VIDEO_MB` defaults to 20. Whisper.cpp CPU work can be slow for long videos. Render Free can have limited CPU/RAM and ephemeral disk.

## Local development

Requires Docker for the complete Whisper.cpp + Argos + FFmpeg runtime. The image build downloads models and can take several minutes.

```bash
cp .env.example .env
# set BOT_TOKEN, ADMIN_IDS and a random WEBHOOK_SECRET_TOKEN
# set MINI_APP_URL to the HTTPS URL of this service

docker build -t hendy-admini-vietsub .
docker run --rm -p 3000:3000 --env-file .env hendy-admini-vietsub
```

For local testing, Telegram webhook needs an HTTPS URL reachable by Telegram; a local port alone does not receive Telegram webhooks.

## Render deployment

1. Put these files in a GitHub repository and connect the repo to Render as a Docker Web Service or Blueprint.
2. In Render → Environment, set `BOT_TOKEN` (fresh token), `ADMIN_IDS`, and `WEBHOOK_SECRET_TOKEN` (a random string made of letters, numbers, `_` or `-`).
3. Set `MINI_APP_URL` to `https://<service-name>.onrender.com`. The app also serves `/`, `/style.css`, and `/app.js`.
4. Set `CORE_BACKEND_URL` if you still use the original remote core backend. `WEB_APP_URL` is an existing legacy target URL.
5. Confirm `GET /api/health` returns `{"ok":true,...}`. Then use `/start` in Telegram.
6. Mount a Render Persistent Disk at `/var/data` for persistent settings and set `SETTINGS_FILE=/var/data/user-settings.json`. If your plan does not support disks, settings can be lost after redeploy.

The app automatically sets Telegram webhook to `WEBHOOK_URL` or `${RENDER_EXTERNAL_URL}/webhook` when it starts. Do not run another polling process with the same token while this webhook instance is active.

## Required environment variables

| Variable | Purpose |
|---|---|
| `BOT_TOKEN` | Fresh token generated by @BotFather; required |
| `ADMIN_IDS` | Comma-separated Telegram numeric IDs allowed into Admini modules |
| `SUBTITLE_ALLOWED_IDS` | Extra IDs allowed to run local subtitle jobs (blank means admins only) |
| `WEBHOOK_SECRET_TOKEN` | Optional Telegram webhook secret; recommended in Render |
| `MINI_APP_URL` | Public HTTPS URL of this service/Mini App |
| `CORE_BACKEND_URL` | Existing core backend URL used by legacy Ktor commands/Vietsub shortcut |
| `WEB_APP_URL` | Existing legacy web app URL |
| `MAX_VIDEO_MB` | Max source file size; Bot API cloud defaults to 20 MB |
| `SETTINGS_FILE` | JSON settings path; use persistent disk path in production |
| `WHISPER_CPP_PATH`, `WHISPER_MODEL_PATH`, `FFMPEG_PATH`, `PYTHON_PATH` | Optional runtime executable/model overrides |

## Important boundaries

- The V3 Admini Mini App action endpoint authenticates the user and confirms the action selection, but it is still a safe integration point rather than a complete admin/database implementation.
- Legacy user wallets, account lists, and state are still in-memory mocks in the provided source. Do not use them as a real payment or credential vault without a proper database, access controls, audit logging, and compliance review.
- Subtitle processing returns files to the Telegram conversation; bots cannot alter videos already playing in Telegram's native viewer.
